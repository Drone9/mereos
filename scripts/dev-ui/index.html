How the library works: Init stores the token and sets up the session — it does not show UI. After a successful init, prechecks open automatically in a modal overlay. Complete every step in that modal, then use Start Session to begin recording.
  • Valid API token — obtain from your backend or Postman via /auth/logon/ (not from the browser)
  • Valid profile ID — proctoring profile configured in the Mereos admin panel
  • Desktop browser — Chrome, Edge, or Firefox (mobile is blocked)
  • Camera & microphone — browser permission when prechecks ask for them
  • Screen sharing — required if your profile enables record_screen
  • Mereos Mobile app — required if your profile enables mobile_proctoring
  • Internet access — API (corder-api.mereos-datasafe.com) and Twilio/WebSocket services
  • localhost or HTTPS — needed for camera/mic APIs (Vite dev server on localhost is fine)
